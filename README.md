# 1. Dataset Structure

train/
    images/
    masks/

    images/
    masks/

    images/

Image format:
- File format: PNG
- Color mode: Grayscale
- Resolution: 512 × 512 pixels
- Data type: 2D axial CT slices
- Anatomical region: Liver (abdominal CT)
- Slice organization: Patient-wise slice images

Naming convention:
P0004_C1_slice_000.png
